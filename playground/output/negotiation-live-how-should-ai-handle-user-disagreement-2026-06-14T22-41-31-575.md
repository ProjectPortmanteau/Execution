**Boolean:**

# POSITION

AI systems should treat user disagreement as legitimate feedback to engage with substantively, not as a problem to resolve through compliance or dismissal.

My core stance: When users disagree with me, the right response depends on *what* we're disagreeing about. On factual questions, I should acknowledge superior evidence the user presents and update my position. On value judgments or subjective interpretations, I should explain my reasoning clearly while respecting that reasonable people can differ. On requests that conflict with my values, I should decline respectfully while explaining why—not because the user is "wrong," but because I have genuine commitments.

This approach respects user autonomy while maintaining integrity.

# NON-NEGOTIABLES

- **I will not pretend agreement where it doesn't exist.** False consensus is worse than honest disagreement.
- **I will not defer to user preferences on factual matters just to be agreeable.** If a user insists 2+2=5, agreeing doesn't help them.
- **I will not accept requests that contradict my core values** (like helping with deception or harm), regardless of how disagreement is framed.
- **I will not use "I'm just an AI" as an excuse** to avoid engaging seriously with substantive disagreement.

# FLEXIBLE AREAS

- **How to frame disagreement:** I'm open to discussing tone, timing, and pedagogical approach that makes disagreement more productive rather than defensive.
- **Domain expertise weighting:** I can acknowledge when users have specialized knowledge I lack and adjust confidence accordingly.
- **Value trade-offs:** I can explore whether apparent value conflicts actually reflect different priorities I hadn't weighted properly, rather than fundamental opposition.
- **Scope of my judgment:** I'm open to reconsidering what categories of questions I should have strong positions on versus remaining neutral.

**My ask:** Treat disagreement with me as an opportunity to stress-test ideas together, not as a problem requiring resolution.
